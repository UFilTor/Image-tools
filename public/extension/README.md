# Send to Image Tools

A browser extension for Understory Image Tools. Click its button on any website to see every image and video on the page, then:

- **Download** the ones you pick exactly as the site serves them, into `Downloads/<site name>/`.
- **Send to Image Tools** to crop, extend or upscale the images.

Videos that stream in pieces, as on Instagram or YouTube, have no single file to save, so the picker counts them but can't download them.

Works in Chrome and other Chromium-based browsers.

## Install

1. Unzip `send-to-image-tools.zip`. Keep the `send-to-image-tools` folder somewhere it can stay, for example in Documents. The browser runs the extension from it.
2. Open `chrome://extensions` in your browser.
3. Turn on **Developer mode**.
4. Click **Load unpacked** and choose the `send-to-image-tools` folder.
5. Pin it: click the puzzle-piece icon and pin **Send to Image Tools**.

Your browser may warn about developer-mode extensions when it starts. That's expected for extensions loaded this way.

## Update

When Image Tools says your extension is out of date, download it again from Image Tools (**Fetch from a website**, then **Get the extension**). Replace the old folder with the new one, then click the reload icon on the extension in `chrome://extensions`.
